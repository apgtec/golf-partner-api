    Schema¶

    The normative contract, as GraphQL SDL: the schema the endpoint serves to partners. Field names, types and nullability are authoritative; see Introspection. The raw file is partner-schema.gql.

    # Bolt6 golf data API: partner schema
#
# Contract version: 1.1.0-draft
#
# This is the schema the endpoint serves to partners, generated by introspection with a partner token.
# It is normative: every operation in operations/ is validated against it. What SDL cannot say (units,
# coordinates, time, delivery, auth, errors, versioning) is in docs/reference.md; worked examples are in
# docs/integration.md.
#
# Two directions:
#   mutations (you -> Bolt6): tournament, course, rounds, groups, stroke reports (upsert*, retractStroke)
#   queries/subscriptions (Bolt6 -> you): ball positions, pin and tee positions, and what you sent
#
# The filter (`*_bool_exp`), ordering (`*_order_by`) and cursor (`*_stream_cursor_*`) inputs are generated;
# read them as the arguments each root field accepts.

schema {
  query: query_root
  mutation: mutation_root
  subscription: subscription_root
}

"""whether this query should be cached (Hasura Cloud only)"""
directive @cached(
  """measured in seconds"""
  ttl: Int! = 60

  """refresh the cache entry"""
  refresh: Boolean! = false
) on QUERY
